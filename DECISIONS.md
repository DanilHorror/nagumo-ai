# Ключевые решения

Черновик. Перепиши каждый пункт своими словами.

1. **LLM на клиенте, голос на сервере.** GPU под сервер — от ~$190 в месяц; у игроков видеокарта уже есть. Голос остался на сервере из-за ограничений клиентского API Simple Voice Chat.
2. **Три уровня модели.** Игровые видеокарты сильно различаются по VRAM: 1.5B для встроенной графики, 3B по умолчанию для 6–8 ГБ, 7B для 10–12 ГБ. Привязка уровня к модели — в одном месте (`ModelManager`).
3. **GigaAM для распознавания.** Модель Сбера, обученная на русской речи; по замерам авторов точнее Whisper на русском. Запускается через onnx-asr. (Проверить своим замером WER — задача из плана.)
4. **Отдельные HTTP-сервисы моделей.** STT и TTS — отдельные процессы с простым API: их можно перезапускать, менять и масштабировать независимо от сервера игры.
5. **Индекс рецептов вместо LLM для фактов.** Модель путает крафты; точные данные из модов подставляются в контекст, а не угадываются.
6. **Модуль brain изолирован.** Чтобы при необходимости вернуть инференс на сервер, заменив только транспорт.
