# NAGUMO AI — сборка и запуск скелета (Этап 1)

## Что это

Мультимодульный Fabric-проект для Minecraft 26.2:

- `verity-common` — общие пакеты (сетевые сообщения клиент↔сервер), логики нет.
- `verity-client` — мод "НАГУМО ИИ", который получают игроки. Логики ИИ нет —
  только отображение того, что прислал сервер.
- `verity-server` — приватный серверный мод. Вся логика ИИ будет только здесь
  (сейчас — заглушка-эхо, реальный ИИ появится на этапе 4).

## Важно: почему проект может не собраться с первого раза

Я писал этот код в облачной песочнице, у которой закрыт доступ к
`maven.fabricmc.net`, `piston-meta.mojang.com` и другим серверам Minecraft/Fabric —
то есть я не мог скачать реальные зависимости и прогнать сборку здесь. Версия
Minecraft 26.2 вышла уже после моего среза знаний (конец января 2026), поэтому
часть API я указал по best-guess на основе более старых версий Fabric API.
Скорее всего Gradle-синк в IntelliJ пройдёт, но что-то из следующего списка
может потребовать правки — **если сборка упадёт, просто пришли мне текст ошибки,
я поправлю**.

### Точки риска (проверить в первую очередь, если ошибка)

1. **`gradle.properties` → `yarn_mappings=26.2+build.1`** — номер сборки маппингов
   я не мог проверить. В IntelliJ/браузере можно посмотреть актуальный билд на
   https://fabricmc.net/develop/ (выбрать 26.2) или на Fabric Meta API.
2. **`fabric_version=0.152.1+26.2`** — аналогично, точная версия Fabric API под
   26.2 могла измениться.
3. Названия методов кодеков в `verity-common/.../network/*.java`:
   `PacketCodecs.STRING`, `PacketCodecs.VAR_INT`, `PacketCodecs.DOUBLE`,
   `PacketCodec.tuple(...)`, `.xmap(...).cast()` — сигнатуры этих API иногда
   меняются между минорными версиями Minecraft.
4. `ServerCommandSource.sendError(...)` / `.sendFeedback(...)` — в новых версиях
   иногда меняют сигнатуру (например добавляют `boolean` параметр или требуют
   `Supplier<Text>` для обоих методов).
5. `ServerPlayConnectionEvents.JOIN` / `ClientPlayConnectionEvents.JOIN` —
   сигнатура коллбэка (`handler, sender, server/client`) бралась по последним
   известным мне версиям Fabric API.
6. `CommandRegistrationCallback` — я использовал пакет `v2`; если в 26.2 остался
   только `v1` (без `environment` параметра в лямбде), нужно будет убрать третий
   параметр коллбэка.
7. `net.fabricmc.fabric.api.client.command.v2.ClientCommandRegistrationCallback`
   и `ClientCommandManager` — аналогично, актуальны на момент моего среза знаний.

Ни одна из этих вещей не влияет на архитектуру — это только имена методов/версии,
которые Gradle-синк в IntelliJ подскажет через автодополнение и подсветку ошибок.

## Как собрать и запустить

1. Открой папку `NAGUMO_AI` в IntelliJ IDEA как Gradle-проект (File → Open →
   выбрать папку с `settings.gradle`).
2. Дай Gradle синхронизироваться — на первом запуске он реально скачает
   Minecraft 26.2, маппинги и Fabric API через твой интернет (это может занять
   несколько минут).
3. Если синк упал с ошибкой — пришли мне текст ошибки, поправлю код или версии.
4. После успешного синка появятся Gradle-таски `runServer` и `runClient`
   (Fabric Loom добавляет их автоматически для каждого модуля с `fabric-loom`).
   Обрати внимание: сейчас плагин `fabric-loom` применяется во всех трёх
   модулях по умолчанию (см. корневой `build.gradle`) — таски `runServer`/
   `runClient` физически появятся у всех трёх, но реально имеет смысл
   использовать только `verity-server:runServer` и `verity-client:runClient`.

## Как проверить, что всё работает

1. Запусти `verity-server:runServer` (поднимется тестовый dev-сервер).
2. В отдельном запуске — `verity-client:runClient`, зайди на `localhost`.
3. При входе должно прийти сообщение вида:
   `Твой ИИ-компаньон теперь с тобой. Его зовут 5H3Y. Переименовать: /nagumo name <имя>`
4. Команды для проверки:
   - `/nagumo name Рекс` — переименовать компаньона (проверка уникальности имён —
     попробуй занять то же имя вторым игроком/командой, должна быть ошибка).
   - `/nagumo style ironic` — сменить характер (доступны: friendly, ironic,
     business, reserved).
   - `/nagumo style-strangers wary` — сменить отношение к посторонним (доступны:
     friendly, polite, wary).
   - `/nagumo ask привет` — клиентская команда, шлёт вопрос на сервер; должен
     прийти эхо-ответ в чат вида `5H3Y: ты написал "привет" — это заглушка,
     настоящий ИИ появится на этапе 4.`

## Что сознательно отложено на этап 2 (не баг, а решение)

Сущность-компаньон пока не появляется в мире визуально — нет `EntityType`,
рендера, анимаций и звука. Это сделано намеренно: рендер сущности тесно связан
с GeckoLib, которую по плану подключаем именно на этапе 2, и писать
Vanilla-рендер сейчас означало бы потом всё переписывать. Пакеты
`SpawnEntity`/`PlayAnimation`/`PlayAudio`/`MoveEntityTo`/`DespawnEntity` уже
определены и клиент их принимает — сейчас просто логирует, обработка появится
вместе с этапом 2. `ShowText` уже работает по-настоящему (выводится в чат) —
этого достаточно, чтобы проверить связку клиент↔сервер на этом этапе.
